### 关键技术决策
- ECharts 而非 Chart.js：ECharts 对热力图支持更好，中文文档丰富
- 后端聚合统计而非前端聚合：减少传输量，但 JSON 列无法 SQL GROUP BY 用 Python Counter
- 对比功能跨页面传值用 Pinia store（selectedForCompare 数组）
- el-table type="selection" + :selectable 控制最多 4 篇
- 对比表格行列转置：原始按论文 → 表格按字段（computed 计算 compareRows）
